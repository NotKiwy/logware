# Logware

Telegram-бот с открытым кодом: сохраняет удалённые и изменённые сообщения в личных чатах, а также одноразовые фото и видео. Всё сохранённое шифруется ключом пользователя, и сервер прочитать его не может.

Код опубликован для ознакомления.

## Как это устроено

- Бот подключается к аккаунту через Telegram Business (в BotFather это называется Secretary Mode).
- При регистрации в Mini App на устройстве создаётся пара ключей X25519. Приватный ключ хранится в одном из трёх мест на выбор: облако Telegram, защищённое хранилище телефона или у нас на сервере, зашифрованный паролем (Argon2id).
- Сервер шифрует каждое сообщение публичным ключом (libsodium sealed box) и хранит только шифротекст.
- Когда сообщение удаляют или меняют, бот присылает уведомление. Само сообщение расшифровывается в Mini App на устройстве.
- Одноразовые фото и видео тоже сохраняются.

Bot API отдаёт сообщения серверу в открытом виде, поэтому это не E2E, а хранилище, к которому у оператора нет доступа. Подробности на [docs.logware.dev/security](https://docs.logware.dev/security).

## Структура

```
server/   бот и API на Go
web/      Mini App на TypeScript
assets/   исходники анимаций и эмодзи
deploy/   Docker и Caddy
docs/     логотипы
```

## Плагины

SDK для плагинов лежит в `server/sdk`. Сами плагины хранятся отдельно и в этот репозиторий не входят.
